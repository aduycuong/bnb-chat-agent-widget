Sandbox giao diện · Shadow DOM

Thử widget

Nút nổi ở góc màn hình và khung bên phải là cùng một widget. Giao diện nằm trong Shadow DOM nên CSS của trang này không chui vào bên trong.

Tin gửi tới agent trên dev.boxx.vn. Trang này phải đúng allowed origin của kênh.

  1. npm run dev — trang này, sửa code là thấy ngay.
  2. npm run build — ra dist/bnb-chat.js.
  3. npm run preview — mở bản script đã build.
