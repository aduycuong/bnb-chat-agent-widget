Gắn widget

Build ra bnb-chat.js. Có hai cách khởi tạo. Cả hai đều cần publicKey và baseUrl — hai giá trị này không nằm trong file script.

Đang kiểm tra window.BnbChat...

Cách 1 — options trên thẻ script

Gắn data-public-key và data-base-url thì script tự mount khi tải xong. data-mode bỏ trống thì là popup. async được: widget đợi DOM sẵn sàng.

Popup

<script
  src="https://bnb-chat-agent.bienhinh.vn/embed/bnb-chat.js"
  data-public-key="HfcVbu7VBNew-3JJd4xPSLNWaNGCpJaw"
  data-base-url="https://bnb-chat-agent.bienhinh.vn/"
  data-mode="popup"
  data-primary-color="#18181b"
  data-position="bottom-right"
  async
></script>

data-position chỉ dùng cho popup: bottom-right hoặc bottom-left. data-primary-color là màu nhấn #rrggbb.

Inline

<div id="bnb-chat"></div>
<script
  src="https://bnb-chat-agent.bienhinh.vn/embed/bnb-chat.js"
  data-public-key="HfcVbu7VBNew-3JJd4xPSLNWaNGCpJaw"
  data-base-url="https://bnb-chat-agent.bienhinh.vn/"
  data-mode="inline"
  data-target="bnb-chat"
  data-primary-color="#18181b"
  async
></script>

data-target là id của phần tử, không cần dấu #. Có #, . hoặc [ thì coi là selector.

Cách 2 — gọi BnbChat.init()

Thẻ script không có data-public-key. Trang tự gọi init sau khi file đã tải. Có container thì là inline, không có thì là popup. 

<script src="https://bnb-chat-agent.bienhinh.vn/embed/bnb-chat.js"></script>
<script>
  var popup = BnbChat.init({
    publicKey: 'HfcVbu7VBNew-3JJd4xPSLNWaNGCpJaw',
    baseUrl: 'https://bnb-chat-agent.bienhinh.vn/',
    primaryColor: '#18181b',
    position: 'bottom-right'
  });
  var inline = BnbChat.init({
    publicKey: 'HfcVbu7VBNew-3JJd4xPSLNWaNGCpJaw',
    baseUrl: 'https://bnb-chat-agent.bienhinh.vn/',
    container: '#bnb-chat',
    primaryColor: '#18181b'
  });
  popup.open();
  popup.close();
</script>

Một trang có thể có cả hai mode. Script đã có data-public-key thì tự tạo một widget; gọi thêm init() sẽ tạo widget thứ hai.
